## 先分清四种优惠，别被"折扣"两个字骗了

市面上常见的云服务器优惠无非这几类，作用完全不一样：

**首月折扣券**。只对新购的第一期计费周期生效。买1个月就是省1个月，买1年通常只按1个月的金额打折，剩下的11个月按原价走。这类券最大的价值是降低试错成本，不是省钱。

**周期折扣**。按你选的计费周期给折扣，比如年付7折、季付9折。这才是长期成本的大头，一台100元/月的机器年付能省下360元。

**活动折扣**。限时拼团、节日大促这类，折扣力度大但机型固定、时间短，往往只剩几款配置可选。

**积分/返利**。用消费和日常任务攒积分，抵扣续费或者换小面额券。单次金额不起眼，续费的时候能顶一点。

关键区别在于：首月券和周期折扣通常可以叠加，因为它们作用在不同的计费环节；而同类型的券一般不能叠。搞清这一点，后面所有计算都顺了。

## 优惠之外，这几个费用项才是真正影响账单的

折扣率是明面上的，真正让人月底超支的是下面这些。

**独立IP**。云服务器默认多为NAT模式（共享公网IP，可做端口映射），需要独立IPv4要另外买。海外区域普通IP大约5元/月，国内高防机房的独立IP因为独享防御，价格高出一大截。日本还有300G+高防IP可选，30元/月。

**流量用完后的限速**。限流量机型把当月流量用光后会限速到1M或5M，可以买流量包恢复。雨云的规则是每月用不完的流量自动结转到下个月，不清零。所以流量别按峰值月买，按平均月买更划算。

**硬盘扩容**。系统盘通常是30GB起步，扩固态约0.4元/GB/月，机械盘约0.1元/GB/月。大容量存储场景选机械盘，成本差四倍。

**备案**。国内机房对大陆地区的网站和常用端口有备案和过白要求，香港、美国、日本节点免备案。如果你的项目不想走备案流程，选区域的时候就别只看价格。

**纯练手、学Linux、跑点小脚本**：重庆1核1G（18元/月）或温州2核2G（38元/月）配上首月5折券，一个月不到10元。用1元试用先跑一天也行。

**面向国内用户、要防御**：温州或襄阳，自带100G到200G防御，独立IP是额外成本但防御不额外收费。这类机房和海外机的账要分开算，别拿月付价格直接比。

**开MC服务器**：镇江或宁波的游戏云VPS，看单核性能而不是核数。

**阶段性项目**：选按天或按月付，用完就删。年付7折看着香，但只对确定长期跑的业务成立。

## 常见问题

**首月5折券和年付7折能同时用吗？**
能。两张券作用在不同环节，一个打首期金额，一个打周期总价，社区经验里还有再叠一张8折新购券的玩法，但积分商城的券的库存和门槛会变，以你下单时页面实际可用的券为准。

**优惠券在哪里领？**
注册并绑定微信后自动发放首月5折券；其他券在积分商城，用积分兑换，不定时上新。

**买错了能退吗？**
7天内无理由退款，每个账号限3次机会。不确定配置是否够用，可以先买低配跑一周，再按天补差价升配。

**流量超了会直接扣钱吗？**
不会自动扣。流量用尽后限速到1M或5M，你需要主动买流量包才恢复速度。雨云支持关闭弹性计费，不用担心被刷爆流量后账单失控。

**价格会不会我看的时候和买的时候不一样？**
云服务的价格随机房、线路和活动实时调整。上面所有数字是撰写时的官网标价，下单前在配置页再确认一次，尤其是活动机型和券的有效期。
